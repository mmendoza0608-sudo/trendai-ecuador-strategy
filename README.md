# TrendAI Ecuador Strategy Hub

Micrositio estático para presentar la estrategia de territorio, cuentas, white spaces, verticales, ecosistema y arquitectura de ingresos.

## Publicar en GitHub Pages

1. Crea un repositorio nuevo en GitHub, por ejemplo `trendai-ecuador-strategy`.
2. Sube `index.html` a la raíz del repositorio.
3. En **Settings → Pages**, selecciona **Deploy from a branch**.
4. Selecciona la rama `main` y carpeta `/ (root)`.
5. GitHub publicará el sitio en una URL del tipo `https://TU-USUARIO.github.io/trendai-ecuador-strategy/`.

## Criterio de datos

- `C`: confirmado.
- `H`: hipótesis comercial razonada.
- `V`: por validar.
- `△`: white space explícito.

Salvo Banco Guayaquil, el footprint detallado por producto no se presenta como hecho confirmado.
